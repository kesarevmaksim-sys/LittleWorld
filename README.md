# LittleWorld

Нативное iOS-приложение-справочник по карточкам настольной игры «Маленький мир» (*Small World*). Приложение помогает просматривать народы и способности, собирать пары для партии и держать выбранные пары на виртуальном столе.

Это неофициальный учебный/личный проект, не связанный с издателями игры.

## Возможности

- Каталог из 45 способностей и 37 народов.
- Поиск карточек по названию.
- Выбор одной способности и одного народа для добавления на Стол.
- Проверка повторов: одна и та же способность или народ не могут попасть на Стол дважды.
- Экран «Стол» с зацикленной каруселью добавленных пар.
- Просмотр списка всех пар на Столе.
- Удаление текущей пары.
- Открытие карточки для чтения с увеличением и перемещением изображения.
- Поддержка книжной и альбомной ориентаций.

## Запуск

1. Откройте [LittleWorld.xcodeproj](LittleWorld.xcodeproj) в Xcode.
2. Выберите iPhone Simulator или подключённый iPhone в качестве устройства запуска.
3. Для запуска на физическом iPhone укажите свою команду разработчика в **Signing & Capabilities** и включите на устройстве Developer Mode.
4. Нажмите `⌘R`.

Минимальная версия iOS в проекте — **26.5**.

## Как пользоваться

1. На главном экране откройте **Каталог**.
2. Отметьте по одной карточке в разделах «Способности» и «Народы».
3. Нажмите «Добавить пару на стол».
4. Откройте **Стол** и листайте пары горизонтальным свайпом.
5. Нажмите на карточку на Столе, чтобы открыть её для подробного чтения.

## Данные и изображения

Тексты и названия находятся в [LittleWorld/Data/CardDescriptions.json](LittleWorld/Data/CardDescriptions.json). Для каждой записи сохранены:

```json
{
  "type": "power",
  "name": "Богатые",
  "description": "…"
}
```

`CardRepository` загружает JSON при запуске и сопоставляет записи с изображениями из `Assets.xcassets` по порядку внутри типа:

- способности: `power-001`, `power-002`, …;
- народы: `race-001`, `race-002`, ….

Поэтому при изменении порядка элементов в JSON необходимо соответственно проверить совпадение с изображениями.

## Структура

```text
LittleWorld/
├── Data/                 # JSON и загрузчик карточек
├── Models/               # GameCard, CardPair, CardKind
├── Stores/               # состояние виртуального Стола
├── Views/                # основные экраны
│   └── Components/       # переиспользуемые SwiftUI-компоненты
├── Assets.xcassets/      # карточки, фоны и иконка приложения
├── ContentView.swift     # точка входа интерфейса
└── LittleWorldApp.swift  # точка входа приложения
```
